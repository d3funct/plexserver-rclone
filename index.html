Personal Google Drive integration

plexserver-rclone

A personal installation of rclone that connects its owner's Google Drive account to local file storage and Plex media playback.

What the integration does

With the account owner's authorization, rclone uploads selected files and their related folders to Google Drive. It can read those files back through a filesystem mount so local software, including Plex, can play them. The owner controls transfers, caching, and file removal.

Google account access

This installation requests the drive.file permission. It is intended to work with files and folders created through this installation, including their names, sizes, timestamps, checksums when available, and contents. Authorization happens through Google's sign-in and consent flow.

This website provides information about the integration. It has no sign-in form and does not access visitors' Google Drive accounts.

Privacy and contact

Read the Privacy Policy for information about access, storage, retention, and revoking authorization, and the Terms of Use for the scope of this personal setup.

Questions can be sent through the project's issue tracker. Issues are public; do not include credentials or private file details.

This is an independent personal configuration using rclone. It is not an official Google or Plex service.
