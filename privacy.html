Data practices

Privacy Policy

Effective date: October 10, 2026

This policy describes the personal plexserver-rclone integration maintained by GitHub user d3funct, and this informational website.

Data accessed and purpose

The integration uses Google's OAuth consent flow and the drive.file scope. Rclone can access files and folders created through this installation, including contents and metadata such as names, folder relationships, sizes, timestamps, and available checksums. It may also read storage quota information available through the Drive API.

This data is used to transfer and organize the owner's selected files, verify transfers, and retrieve file data for playback by the owner's configured media software. File modification or deletion occurs only through actions or automation configured by the owner.

Storage and retention

Uploaded files are stored in the owner's Google Drive account. Local source files, downloaded data, playback caches, and operational logs may be stored on the owner's equipment. Logs can contain filenames, paths, transfer details, and error messages. OAuth tokens are stored in the owner's rclone configuration and enable continued access without storing a Google account password.

Drive files remain until the owner removes them, subject to Google's account and retention policies. Local files, caches, logs, and credentials remain according to the owner's configuration and cleanup actions. The owner controls access to this equipment and its stored data.

Sharing and other services

The integration communicates with Google Drive to perform the owner's requested file operations and can supply file data to the owner's configured Plex installation. Any sharing or remote playback configured separately in Drive or Plex is controlled by the owner. The integration does not sell Google user data or use it for advertising or AI model training.

Google Drive and Plex operate under their own applicable privacy policies. This website's public source repository contains informational page content, not the integration's private file data or credentials.

Revoking access and deletion

The owner can stop the local integration and revoke its access through Google Account third-party connections. Revoking authorization does not automatically delete uploaded Drive files, local copies, logs, or cached data. Those must be removed separately by the owner where stored. The owner can also remove the local rclone credentials after stopping the integration.

This website

This informational site contains no analytics scripts, sign-in forms, or advertising. It does not request Google account access. GitHub Pages hosts the site and may process visitor information, including IP addresses, for security and service operation under the GitHub Privacy Statement.

Google API Limited Use

The integration's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.

Contact and updates

Contact the maintainer through the project's issue tracker or the support email shown on the Google consent screen. Public issues must not contain secrets or private file details. Material changes to the integration's data practices will be reflected on this page with an updated effective date.
